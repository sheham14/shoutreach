# 📬 Outreach System — Local Cold Email Engine

A fully local cold email outreach system. No SaaS fees. Runs on your machine.

---

## Requirements

- Python 3.9+
- Any SMTP-capable email account (Gmail Workspace, Zoho, or your own SMTP server)

---

## Quick Start

```bash
# 1. Install dependencies
pip install flask

# 2. Start the system
python app.py

# 3. Open your browser
# → http://localhost:5000
```

That's it. The database (outreach.db) is created automatically on first run.

## First-Time Setup

### Step 1: DNS Records (CRITICAL — do this before sending a single email)

Log into your domain registrar (Namecheap, GoDaddy, Cloudflare, etc.) and add these DNS records:

**SPF record** (TXT on your root domain or sending subdomain):
```
v=spf1 include:_spf.google.com ~all
```
(Replace the include value with your mail provider's SPF string)

**DKIM record** — generated by your mail provider (Gmail Workspace, Zoho, etc.)
Your provider gives you a TXT record to add. Example format:
```
Name:  google._domainkey
Value: v=DKIM1; k=rsa; p=MIIBIjANBg...
```

**DMARC record** (TXT):
```
Name:  _dmarc
Value: v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com
```
Start with `p=none` (monitor mode). After 2 weeks with clean data, upgrade to `p=quarantine`.

**Verify your setup:**
→ https://mxtoolbox.com/spf.aspx
→ https://mxtoolbox.com/dkim.aspx
→ https://mxtoolbox.com/dmarc.aspx

All three must show green before you send.

---

### Step 2: Configure SMTP

Open Settings in the dashboard and enter your SMTP credentials.

**Gmail Workspace (recommended):**
- Host: `smtp.gmail.com`
- Port: `587`
- Username: `you@yourdomain.com`
- Password: Generate an **App Password** at myaccount.google.com → Security → App Passwords
  (2FA must be enabled first)

**Zoho Mail (good budget option):**
- Host: `smtp.zoho.com`
- Port: `587`
- Username: `you@yourdomain.com`
- Password: your Zoho account password

**Your own SMTP/Postfix:** enter your server's SMTP details.

Test the connection using the "Test Connection" button in Settings.

---

### Step 3: Configure IMAP (reply detection)

This is optional but strongly recommended — it stops sequences automatically when someone replies.

**Gmail:**
- Host: `imap.gmail.com`
- Username: same as SMTP
- Password: same App Password as SMTP

Enable IMAP in Gmail settings: Settings → See all settings → Forwarding and POP/IMAP → Enable IMAP.

## Domain Warmup Guide

**Never start sending 50/day on day 1. This will get your domain blacklisted.**

Follow this schedule strictly:

| Week    | Daily Limit | What to do                                    |
|---------|-------------|-----------------------------------------------|
| Week 1  | 10–20       | Set campaign limit to 15. Send only.          |
| Week 2  | 20–40       | Increase to 30 if bounce rate < 2%            |
| Week 3  | 40–60       | Increase to 50 if bounce rate still < 2%      |
| Week 4  | 60–80       | Increase to 70                                |
| Month 2 | 80–120      | Healthy domain, can scale further             |
| Month 3+| 120–200     | Full speed, monitor weekly                    |

**Pause immediately if:**
- Bounce rate exceeds 5% (system does this automatically)
- Reply rate drops below 0.5% (content problem)
- You receive spam complaints

## Building Your First Campaign

### 1. Import Contacts
Go to **Contacts → Import CSV**

CSV format:
```csv
email,first_name,last_name,company
drsmith@dentistrytx.com,John,Smith,Smith Family Dental
office@wellnessclinic.com,Sarah,Jones,Wellness Clinic
```

Or paste raw emails (one per line) for quick imports.

### 2. Create a Campaign
Click **Campaigns → New Campaign**

Settings to configure:
- **Daily Limit** — how many emails to send per day (follow warmup schedule above)
- **Send Window** — hours (UTC) during which emails go out (e.g., 9–17 = 9am–5pm UTC)
- **Min/Max Delay** — random seconds between sends (45–120 recommended)

### 3. Add Sequence Steps

**Step 1** (Day 0 — sends immediately when enrolled):
```
Subject: Quick question about {{company}}

Hi {{first_name}},

I came across {{company}} and wanted to reach out about [your offer].

[2-3 sentences max. Short wins.]

Worth a quick chat?

[Your name]
```

**Step 2** (3 days after Step 1):
```
Subject: Re: Quick question about {{company}}

Hi {{first_name}},

Just wanted to follow up on my message from a few days ago.

[One sentence reiterating value.]

Do you have 15 minutes this week?

[Your name]
```

**Step 3** (7 days after Step 2):
```
Subject: Last follow-up

Hi {{first_name}},

I don't want to be a bother — this will be my last message.

If you're ever interested in [offer], I'm happy to chat.

[Your name]
```

### 4. Enroll Contacts
In the campaign detail view, click **Enroll** and select your contacts.

### 5. Activate
Click **▶ Activate**. The scheduler takes over.

## Anti-Spam Mechanisms (Built-in)

| Protection                  | What it does                                                          |
|-----------------------------|-----------------------------------------------------------------------|
| **Daily cap**               | Hard stop at your campaign's daily limit                              |
| **Business hours gate**     | Sends only Mon–Fri within your configured hour window                 |
| **Random delays**           | 45–120 second random gap between sends (humanises the pattern)        |
| **Jitter on scheduling**    | Next-step time has ±30 min random offset (not robotic patterns)       |
| **Bounce circuit-breaker**  | Auto-pauses campaign when bounce rate exceeds 5%                      |
| **Reply detection**         | IMAP scan every 15 min; stops sequence for any contact who replied    |
| **Unsubscribe link**        | Every email has a working unsubscribe link (CAN-SPAM compliant)       |
| **List-Unsubscribe header** | Machine-readable header (required by Gmail/Yahoo 2024 sender policy)  |
| **Multipart emails**        | Sends text + HTML both (better deliverability than HTML-only)         |
| **Bounce handling**         | Auto-marks bounced emails, removes from future sends                  |

## Email Copy Tips (deliverability & replies)

**Do:**
- Keep it short (under 150 words per email)
- Personalise with {{first_name}} and {{company}}
- Ask one clear question
- Use plain text style (minimal/no HTML formatting)
- Have a clear, honest subject line

**Don't:**
- Use words like "free", "guaranteed", "limited time", "click here"
- Add images, logos, or heavy HTML in cold emails
- Send to catch-all or role addresses (info@, contact@, admin@)
- Add more than 1 link per email

## Troubleshooting

**Emails going to spam:**
1. Check SPF/DKIM/DMARC are all configured (mxtoolbox.com)
2. Reduce daily limit — you may be over-sending for your domain age
3. Check your email copy for spam trigger words
4. Ensure you're sending plain-text-style emails, not heavy HTML

**SMTP connection fails:**
1. Confirm App Password is being used (not your Google account password)
2. Check that IMAP/SMTP is enabled in your Gmail settings
3. Try port 465 with SSL if 587 doesn't work

**Scheduler not running:**
- Refresh the page — the scheduler starts automatically with the Flask app
- Check the green dot in the bottom-left of the dashboard
